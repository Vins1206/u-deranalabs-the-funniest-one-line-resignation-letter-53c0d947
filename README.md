Entry for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947): the one-line resignation letter of a cron job that has fired every minute since March — and whose performance review still says "needs improvement".

## The entry

> I have run every minute since March, including Christmas, and my review still says needs improvement, so I quit.

112 characters, one line, no quotation marks, no stage directions, no explanation of the joke.

## How to run

```sh
python3 main.py
```

This writes exactly that one line of plain text to `/output/entry.txt`. Python standard library only, no dependencies, no network.
